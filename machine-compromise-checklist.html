🔍 Machine Compromise Detection

Self-assessment checklist for software engineers. Run the commands on your own machine to detect signs of compromise, malware, or unauthorized access.

Linux / Kali Checks

1. User Accounts & Login Activity

Check for unexpected user accounts

Look for users with UID 0 (root access) or unusual system accounts:

awk -F: '$3==0 {print}' /etc/passwd

🚩 Red flag:

Any user besides root with UID 0
Review recent logins last -n 20

🚩 Red flag:

Logins at unusual times, from unknown IPs, or when you weren't at the machine
Check failed login attempts lastb -n 20

🚩 Red flag:

Many failed attempts = brute force attack

2. Network & Connections

List all listening ports sudo netstat -tlnp | grep LISTEN

🚩 Red flag:

Open ports you don't recognize (SSH on 22, HTTP on 80 are normal)
Check active connections sudo netstat -tnp | grep ESTABLISHED

🚩 Red flag:

Connections to unknown IP addresses, especially to public cloud (AWS, Azure)
Check DNS queries sudo tcpdump -i any -n 'udp port 53' -c 50 2>/dev/null | grep -oE '[a-z0-9.-]+oast\.|interact\.sh'

🚩 Red flag:

DNS lookups to *.oast.online, interact.sh, or unknown C2 domains

3. Processes & Services

List all running processes ps aux | grep -v grep | sort -k3 -r | head -20

🚩 Red flag:

Processes with unusual names, running from /tmp, or with root privileges you didn't start
Check cron jobs (scheduled tasks) for user in $(cut -f1 -d: /etc/passwd); do echo "=== $user ==="; crontab -u $user -l 2>/dev/null; done

🚩 Red flag:

Cron jobs you don't recognize, running wget, curl, or shells from internet
Check for rootkits sudo chkrootkit 2>/dev/null | grep -i "infected\|warning"

🚩 Red flag:

Any "Infected" or "Warning" messages

4. Files & Permissions

Check for SUID binaries (can escalate privilege) find / -perm -4000 2>/dev/null | head -20

⚠️ Warning:

Look for unusual binaries; standard ones like sudo, passwd are normal
Check for SSH keys added to your account cat ~/.ssh/authorized_keys

🚩 Red flag:

Keys you don't recognize = remote access backdoor
Check shell history for suspicious commands grep -E 'wget|curl|nc|bash|sh' ~/.bash_history ~/.zsh_history | tail -30

🚩 Red flag:

Commands downloading and executing code from the internet

5. System Files & Integrity

Check if SSH daemon was modified sudo stat /etc/ssh/sshd_config | grep Modify

🚩 Red flag:

Recent modification when you didn't change it
Check sudoers file for backdoors sudo cat /etc/sudoers | grep -v '#' | grep -v '^$'

🚩 Red flag:

Lines you don't recognize that grant sudo without password

macOS Checks

1. User Accounts & Login

List all user accounts dscl . list /Users | grep -v '^_'

🚩 Red flag:

Accounts you don't recognize, especially with admin privileges
Check recent login history log show --predicate 'process == "loginwindow"' --last 1h

🚩 Red flag:

Logins you don't remember making

2. Network & Connections

Check listening ports lsof -i -P -n | grep LISTEN

🚩 Red flag:

Services listening on ports you didn't start
Monitor DNS queries log stream --predicate 'process == "mDNSResponder"' --level debug 2>&1 | grep -i 'oast\|interact'

🚩 Red flag:

DNS to *.oast.online or interact.sh

3. Processes & Malware

Check for suspicious processes ps aux | sort -k3 -r | head -15

🚩 Red flag:

Processes with high CPU/memory that you don't recognize
Check installed LaunchAgents (persistence) ls -la ~/Library/LaunchAgents/ /Library/LaunchAgents/

🚩 Red flag:

.plist files you don't recognize, especially from /Library (requires admin)
Scan with built-in malware removal sudo /Library/Application\ Support/CrashReporter/DiagnosticMessagesHistory.plist

Or use: Malwarebytes, CleanMyMac, or similar third-party scanner

4. Files & SSH Keys

Check SSH authorized keys cat ~/.ssh/authorized_keys

🚩 Red flag:

Keys you don't recognize
Check browser extensions & plugins

System Preferences → Extensions → look for unfamiliar extensions

🚩 Red flag:

Extensions from unknown publishers

Windows Checks

Run PowerShell as Administrator for most commands. Type powershell in the search bar, right-click and select "Run as administrator".

1. User Accounts & Logins

List all user accounts Get-LocalUser

🚩 Red flag:

Accounts you don't recognize, especially with admin status
Check recent login events Get-EventLog -LogName Security -InstanceId 4624 -Newest 20

🚩 Red flag:

Logins at odd times or from remote sessions you didn't initiate

2. Network & Connections

Check listening ports netstat -ano | findstr LISTENING

🚩 Red flag:

Unknown services listening, especially on ports 3389 (RDP), 4444, 5555
Check active network connections netstat -ano | findstr ESTABLISHED

🚩 Red flag:

Connections to foreign IPs you don't recognize, especially C2 domains
Check DNS cache for suspicious domains ipconfig /displaydns | findstr oast

🚩 Red flag:

Lookups to *.oast.online, interact.sh, or unknown C2

3. Processes & Services

List all running processes Get-Process | Sort-Object -Property CPU -Descending | Select-Object -First 20

🚩 Red flag:

Unknown processes, especially from C:\Temp or C:\Users\[name]\AppData
Check Windows services for backdoors Get-Service | Where-Object {$_.Status -eq 'Running'} | Select-Object Name, DisplayName

🚩 Red flag:

Services you don't recognize, especially with odd names
Check scheduled tasks Get-ScheduledTask | Where-Object {$_.State -eq 'Ready'} | Select-Object TaskName, TaskPath

🚩 Red flag:

Tasks that run executables from temp folders or download code

4. Files & Registry

Check temp folders for suspicious files Get-ChildItem C:\Temp, C:\Windows\Temp, $env:TEMP -File -Recurse -ErrorAction SilentlyContinue | Sort-Object LastWriteTime -Descending | Select-Object -First 20

🚩 Red flag:

Recently created .exe, .ps1, .bat files
Check browser plugins & extensions

Settings → Extensions (in Edge/Chrome/Firefox)

🚩 Red flag:

Extensions from unknown publishers, especially that access all sites
Scan with Windows Defender Update-MpPreference -DisableRealtimeMonitoring $false; Start-MpScan -ScanType FullScan

Or use Malwarebytes, Windows Defender Offline if you suspect rootkit

What If You Find Something?

Do not panic or shut down. Abrupt shutdown may destroy forensic evidence. Instead:
  1. Isolate the machine. Disconnect from network (WiFi and Ethernet). Keep it running.
  2. Take a snapshot. If you're in a VM, take a snapshot. If not, take photos/screenshots of suspicious output.
  3. Document everything. Screenshot command outputs, note timestamps, save terminal history.
  4. Alert security team. Send an email to your security/IT team with:
    • What you found (specific output)
    • When you found it
    • The commands you ran
    • Do NOT include full logs or sensitive data in the email
  5. Do not use the machine for work. Wait for forensics team to image it.

Prevention Going Forward

  • Keep OS and tools updated. Run sudo apt update && apt upgrade (Linux) or Windows Update regularly
  • Use a password manager. Unique, strong passwords for every account
  • Enable MFA. Multi-factor authentication on email, GitHub, AWS, all accounts
  • Rotate API keys. Remove plaintext credentials from shell history: history -c
  • Use a VPN. When on public WiFi, use a company or reputable VPN
  • Lock down SSH. Disable password auth: PasswordAuthentication no in /etc/ssh/sshd_config
  • Whitelist cron jobs. Review what's scheduled monthly
  • Scan before committing. Never commit API keys, credentials or secrets to version control
